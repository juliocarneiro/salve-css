# __PROJECT_NAME__

An Astro site, styled with [salve-css](https://salve-site-mu.vercel.app).

| Command | |
| --- | --- |
| `npm run dev` | start the dev server |
| `npm run build` | build to `dist/` |
| `npm run preview` | serve the build |

```
src/
  layouts/Layout.astro   imports salve-css and salve-icons, applies the saved theme before paint
  pages/index.astro      the page
public/                  files served as-is
```

Start in `src/pages/index.astro`.

Docs: https://salve-site-mu.vercel.app
