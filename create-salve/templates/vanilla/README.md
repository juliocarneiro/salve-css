# __PROJECT_NAME__

A plain JavaScript site with Vite, styled with [salve-css](https://salve-site-mu.vercel.app).

| Command | |
| --- | --- |
| `npm run dev` | start the dev server |
| `npm run build` | build to `dist/` |
| `npm run preview` | serve the build |

```
index.html    the page
src/main.js   imports salve-css and salve-icons, wires the theme button
public/       files served as-is
```

Start in `index.html`.

Docs: https://salve-site-mu.vercel.app
